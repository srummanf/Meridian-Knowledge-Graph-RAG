# Java

**Type:** Language
**Aliases:** JVM

## Overview

Java is used at Meridian only for the Ledger Service, where the team wanted the
JVM's mature support for precise decimal arithmetic and long-running
transactions.

## Usage at Meridian

Log4j depends on Java.
The Ledger Service depends on Java 17.

## Version

The Ledger Service runs on Java 17 LTS.
