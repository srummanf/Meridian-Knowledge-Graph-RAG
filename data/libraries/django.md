# Django

**Type:** Library
**Aliases:** —

## Overview

Django is a batteries-included Python web framework. At Meridian it is used where
a service benefits from the built-in admin, ORM, and migrations.

## Dependencies

Django depends on Python; it requires Python 3.10 or newer.

## Usage at Meridian

The Auth Service depends on Django.
The Billing Service depends on Django.

## Alternatives

Django is an alternative to FastAPI. Teams choose Django when they want a full
framework and FastAPI when they want a thin async layer.

## Version

Meridian standardises on Django 4.2 LTS.
