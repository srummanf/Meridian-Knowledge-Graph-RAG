# Python

**Type:** Language
**Aliases:** —

## Overview

Python is the primary language at Meridian. Every service except the Ledger
Service is written in Python 3.11.

## Usage at Meridian

Django depends on Python.
FastAPI depends on Python.
SQLAlchemy depends on Python.
Celery depends on Python.

The API Gateway, Auth Service, User Service, Billing Service, Notification
Service, Fraud Service, and Reporting Service are all written in Python.

## Version

Meridian standardises on Python 3.11.
