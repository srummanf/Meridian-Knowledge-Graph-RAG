# FastAPI

**Type:** Library
**Aliases:** —

## Overview

FastAPI is an async Python web framework built on Starlette and Pydantic. It is
Meridian's default choice for new services that expose HTTP or gRPC APIs.

## Dependencies

FastAPI depends on Python; it requires Python 3.8 or newer.

## Usage at Meridian

The API Gateway depends on FastAPI.
The User Service depends on FastAPI.
The Notification Service depends on FastAPI.
The Fraud Service depends on FastAPI.
The Reporting Service depends on FastAPI.

## Alternatives

FastAPI is an alternative to Django for services that do not need a full
framework.

## Version

Meridian standardises on FastAPI 0.110.
