# REST

**Type:** Protocol
**Aliases:** RESTful API, HTTP API

## Overview

REST is the HTTP-based request/response style Meridian uses for external APIs and
for internal APIs that do not need streaming. Payloads are JSON.

## Usage at Meridian

The Public REST API communicates via REST.
The User API communicates via REST.
The Billing API communicates via REST.
The Reporting API communicates via REST.

## Notes

REST is used for every API that external merchant integrations touch, because it
is the lowest-friction option for third-party developers.
